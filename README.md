Drift — Releases

This repository contains only the Windows installers for Drift and the "latest.json" file that the app uses to update itself. The source code is not hosted here.

Installation

Download "Drift_x.y.z_x64-setup.exe" from the "latest release" (../../releases/latest) and run it.

Future versions will be installed directly through the app (Settings › Updates).

Each installer is signed, and the app rejects any update whose signature does not match.
